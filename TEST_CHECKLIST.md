# Test Checklist

## Etap skeleton
- [ ] Build lokalny przechodzi bez błędów.
- [ ] Moduł ładuje się w VCV Rack.
- [ ] Deploy lokalny działa.
- [ ] Deploy na drugi komputer działa (jeśli używany).

## Etap saturator (następny)
- [ ] Każdy tryb saturacji działa sample-by-sample stabilnie.
- [ ] Brak alokacji dynamicznej w ścieżce audio.
- [ ] Parametry nie powodują klików i destabilizacji.
- [ ] Brzmienie trybów jest wyraźnie zróżnicowane.
