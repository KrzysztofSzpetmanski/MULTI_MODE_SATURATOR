# Deploy Two Computers

Ten dokument dotyczy workflow deployu dla projektu **MULTI_MODE_SATURATOR**.

## Status
Projekt jest na etapie skeleton. Deploy służy do szybkiej iteracji i przygotowania pipeline'u pod właściwy development saturatora.

## Kroki
1. Build lokalny.
2. `make deploy-local`.
3. `make deploy-big` (jeśli aktywne).
